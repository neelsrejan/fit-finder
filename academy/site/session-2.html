2. Session 2 · Download without committing

Architecture. This module is the only network path for the UCSD files. It is not imported by the model. CI never calls it. The URLs are the current McAuley Lab links, not the commented-out deepx hosts on the same page. The gzip files land in data/raw and stay out of git.

How this session connects

download.py only fetches the two McAuley Lab URLs and writes gitignored files. clean.py maps each source into REVIEW_COLUMNS. Quality, length, names, and review text stop at this boundary. Later sessions never see them.
