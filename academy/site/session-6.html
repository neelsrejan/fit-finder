1. Session 6 · The page contract, tested without Chrome

Architecture. This parser is the test double for the content script. Both read the same attributes on a demo page: product id, category, price, colors, size-chart rows, and the selected size. CI can check the fixture HTML without launching a browser. The parser does not fetch URLs.

2. Session 6 · The panel only on the demo origin

Architecture. The content script is the browser half of the same contract. It reads the page, calls the local API, and renders a panel. It does not decide which sites it may run on. The manifest does. If the API is down, the panel says so instead of inventing a size.

How this session connects

The content script and pageparse.py both read article.product, the size chart rows, and the size select. The manifest lists localhost and 127.0.0.1 only. A unit test fails if a retailer name appears in the manifest.
