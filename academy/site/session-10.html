1. Session 10 · The card is a formatter

Architecture. The report module does not train and does not simulate. It reads JSON that other scripts wrote and formats sentences around those digits. That is why a resume bullet cannot drift from the model card unless someone edits the prose template. The size-search loss is hard-coded as a sentence because the comparison is part of the result, not an optional footnote.

2. Session 10 · Four sections, two kinds of number

Architecture. The eval report is the single page a hiring manager can read after the model card. It keeps held-out fit metrics, the content ranker, the simulated experiment, and the blocked H and M comparison in separate sections. The function refuses to compute a new number. If a figure is not in the JSON, it cannot appear.

How this session connects

render.py formats digits from docs/metrics. It does not recompute the model. scripts/build_metrics.py is the path that trains, ranks, simulates, and then calls the renderer. The learning site is static files plus the Pages workflow.
