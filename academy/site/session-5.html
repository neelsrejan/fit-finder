1. Session 5 · The contract on the wire

Architecture. Schemas are the product surface. The model code can change internals, but a client of predict-size, recommend, or events depends on these bodies. OpenAPI is generated from them. A missing size is a 422, not a guessed size.

2. Session 5 · Three routes and a frozen bundle

Architecture. The app is the edge. It loads the joblib bundle and the catalog once, validates bodies, and delegates. It does not train, it does not download, and it does not run the simulated experiment. Health reports the two blocked account steps so a reader of the docs page can see them.

1:18 · Andrew · src/fit_finder/api/app.py on main

How this session connects

schemas.py is the contract. app.py loads the bundle and the catalog at startup and returns 503 if a file is missing. /events writes a real local request and marks simulated false. The simulated experiment does not use this route.
