2. Session 7 · The sample size is computed

Architecture. The power helper exists so the number in the readout is a formula, not a typed integer. It is the normal approximation for two proportions with equal allocation. It does not know about fit reviews. The caller passes the control rate from the simulation and a planned treatment rate two points lower.

How this session connects

assumptions.py holds the probabilities. ab.py draws shoppers. power.py turns the control rate and a 2 point planning lift into a sample size. None of these functions read the trained model. The model's directional accuracy stays in the model card.
