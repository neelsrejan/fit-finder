1. Session 1 · Settings and the secret boundary

Architecture. This file is the only place that reads the Kaggle token. The model, the API, and the extension never see the raw key. The repr is the boundary that keeps a log line from becoming a leak, and the allow flag defaults off so importing the package does not download anything.

2. Session 1 · CI proves the repo, not the model

Architecture. CI is the contract that a stranger can install the package and run the tests. It does not download the UCSD files, it does not train the full model, and it does not hold a secret. The second job rebuilds the learning site and fails if the committed pages drift from the generator.

How this session connects

Settings is the only place that reads KAGGLE_KEY. The repr reports set or missing, so a log of the settings object cannot leak the token. CI installs the package and runs pytest. It does not download the UCSD files and it does not call Kaggle.
