Power BI

The dashboard tool for this project is Power BI. This page is not a substitute dashboard.

A free Power BI license cannot create a Publish to web embed code, and it cannot share a report with another person. Publish to web also rejects reports that use report-level DAX measures, which is how the measures in this project are written. Power BI Pro is paid, so it is not used here. Power BI Desktop runs on a Windows computer and is not a public URL.

The files a hiring manager can open are the CSV extracts. They are in the repository at analytics/extracts/ and, on GitHub Pages, under extracts/. fact_shopper.csv and fact_event.csv are simulated. fact_model_score.csv is a sample of held-out predictions from the public UCSD reviews. The build steps are in analytics/powerbi/BUILD.md.

Shopper counts, clicks, and dollar figures in those extracts are simulated. The fit metrics are not.
